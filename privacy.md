# Privacy Policy - Spark in Motion Uploader

Last updated: October 31, 2026

Spark in Motion Uploader is a private tool operated by Naveen Bandla, owner of the Data in Motion YouTube channel. It is used only by the channel owner to publish the channel's own content.

## What the app accesses

With the channel owner's permission, the app uses YouTube API Services to upload videos, set thumbnails, add captions, and create or update playlists on the owner's own channel. It reads basic channel information, such as the channel name and ID, to confirm it is posting to the correct channel.

## What the app stores

The app stores an OAuth refresh token so it can upload new episodes on a schedule. The token is kept privately by the channel owner and is used for no other purpose. The app does not collect, store, sell or share personal data about viewers or any other users, and it does not use cookies or analytics.

## Sharing

No data obtained through YouTube API Services is shared with third parties.

## YouTube and Google policies

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service at https://www.youtube.com/t/terms. Google's handling of data is described in the Google Privacy Policy at https://policies.google.com/privacy.

## Revoking access

Access can be revoked at any time from the Google security settings page at https://myaccount.google.com/permissions. Revoking access stops all uploads immediately. To request deletion of any stored data, email the contact below; stored tokens are deleted within 7 days.
